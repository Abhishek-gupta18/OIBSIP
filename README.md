## 🚆 Internship Projects

### Task 1 — RailReserve: Online Reservation System

**Status:** In Progress

RailReserve is a Java Swing desktop application designed to demonstrate the basic workflow of an online train reservation system.

**Key features planned for the project:**
- User login and credential verification.
- Train selection with automatic train-name population.
- Ticket booking with a unique Passenger Name Record (PNR).
- Booking lookup using a PNR.
- Ticket cancellation with confirmation.
- Booking history with filtering options.
- PostgreSQL database integration using JDBC.

**Technology stack:**
- Java 17
- Java Swing
- PostgreSQL
- JDBC
- Maven
- JUnit 5

[View Task 1 Documentation](Java-Task1-OnlineReservation/README.md)

> This is an educational project. It is not affiliated with IRCTC or Indian Railways and does not issue real tickets or process real payments.

## 🔒 Code Quality and Security

Where applicable, the projects will follow these practices:

- Keep source code organized into meaningful classes and modules.
- Use parameterized SQL queries through `PreparedStatement`.
- Keep database credentials out of committed source code.
- Validate user input before processing it.
- Handle exceptions and database failures gracefully.
- Store passwords using appropriate password-hashing techniques rather than plaintext.
- Use automated tests to verify important business rules.

These practices will be applied according to each project's requirements.
